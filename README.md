# Balbooa Gallery 2.x Language Packs

Official language packs for **[Balbooa Joomla Gallery](https://www.balbooa.com/joomla-gallery)**.

This repository contains the language files used by Balbooa Gallery. Language packs are maintained automatically and are updated as the Gallery extension evolves.

<br>

> **This repository is automatically maintained.**
> Language files should not be edited manually.

<br>
<br>

## 📥 Installing a Language

Language packs are **not installed directly from this GitHub repository**.

Languages are installed from inside **Balbooa Gallery** in your Joomla administrator panel.

For step-by-step instructions, see:

**[Localization and Translation — Balbooa Gallery](https://www.balbooa.com/help/joomla-gallery-documentation/basics/localization-and-translation)**

<br>
<br>

## 🌏 Need Another Language?

Don't see the language you need?

[Contact Balbooa](https://www.balbooa.com/help/contacts) and tell us which language you would like to have available.

We will consider adding it to the available language packs.

<br>
<br>
